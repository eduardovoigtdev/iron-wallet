# Iron Wallet
Iron Wallet é uma aplicação web de gestão financeira pessoal desenvolvida com HTML, CSS e JavaScript puro.
O projeto foi criado com foco em educação financeira, acessibilidade mobile e organização intuitiva de receitas e despesas.


## Preview
Interface moderna inspirada em dashboards fintechs, totalmente responsiva para dispositivos móveis.

## Funcionalidades
- Controle de receitas e despesas
- Dashboard financeiro
- Metas de economia
- Gráficos financeiros com Chart.js
- Persistência de dados com LocalStorage
- Filtros e pesquisa
- Interface responsiva
- Exportação de relatório PDF
- Experiência otimizada para dispositivos móveis

## Tecnologias
- HTML5
- CSS3
- JavaScript Vanilla
- Chart.js
- LocalStorage

## Objetivo
O projeto foi desenvolvido como uma ferramenta gratuita de apoio à educação financeira, buscando oferecer uma solução simples e acessível para ajudar pessoas a organizarem melhor sua vida financeira.
A aplicação foi projetada priorizando a experiência mobile, considerando que muitas pessoas utilizam o smartphone como principal meio de acesso à internet.
